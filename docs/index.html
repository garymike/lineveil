Lineveil

A featherweight scanline overlay for the Windows desktop. Drawn once, composited by Windows, then it gets out of the way.

How it works

  
Each monitor gets one click-through, always-on-top layered window. Lineveil renders the line pattern once, hands it to the Windows compositor, and frees its own copy. From then on the process sleeps until you press the hotkey, change the config, or plug in a display.

  
Because it overlays rather than captures, it needs no screen-recording access and can't see what's on your screen. It's plain C with no C runtime, and config parsing is handled by Windows itself.

Limits

  
Exclusive fullscreen games bypass the Windows compositor, so the overlay won't show there. Borderless fullscreen works. UAC prompts draw above everything by design.
